**Description**

**User impact**

Operators can stop one user or workspace from using up all job capacity. Users and scripts that poll job status will see the new `queued` value before `pending`.

#### CLI validation

```sh
nemo jobs list --filter.status queued
nemo jobs get-status <job-name>
```

Expected:

- A job that is over a configured limit shows `queued`, then moves to `pending`/`active` when capacity frees up.
- Pausing a `queued` Customizer job follows the documented pause/resume table.

#### Additional validation

- Set low limits in the platform config, submit more jobs than the limit, and confirm that no more than the limit are admitted.
- Set `max_concurrent_builds` and confirm that builds return `queued` and start oldest first.
- Commit `e5027fa48` (#3559, admission controller always admits) has no documentation; its intended interaction with the limits needs clarification.

### 3. Stricter and key-wise entity filters

| Field | Value |

| Release-note coverage | `Missing — no docs/about/release-notes/release-0-10-0.mdx` |

**Description**

On key/value fields such as `labels`, `metadata`, or a job's `spec`, filters written in dotted, bracket, or nested JSON form match each named key. Filter shapes that the entity store can't evaluate now return `400 Bad Request`. These include an operator placed directly on a key/value field, an object of plain keys on any other field, mixed operator and plain keys, and operators without the `$` prefix.

**User impact**

API and CLI callers get an explicit error for malformed filters, so they no longer get results that silently mismatch. Existing clients that sent such filters must fix them.

#### CLI validation

```sh
nemo jobs list --filter.source nemo-agents-plugin-execute \
  --filter '{"spec.agent_ref": {"$in": ["default/calc", "research/calc"]}}'
```

Expected:

- The three equivalent `labels` filter forms in `filtering.mdx` return the same results.
- `?filter[labels][$hasKey]=team`, `{"name": {"first": "x"}}`, and `{"created_at": {"gte": "2025-01-01"}}` return `400`.

#### Additional validation

- Please regression test Studio list pages and SDK `list(...)` calls that send filters.

#### Draft release-note text

Filters on key/value fields match per key, and unsupported filter shapes return `400`. Omitted from draft release notes: release-note coverage is `Missing`.

**Description**

A virtual model whose request middleware ends with `nemo-evals-closed-book` strips hosted tools, such as provider web search, from model calls. Harbor built-in agents can name a gateway model by `ref`, and evals sets the agent's base URL and key variables. Each trial gets its own gateway token, a minted `inference`-scoped key when auth is enabled, that is limited to its models.   --request-middleware '[{"name": "nemo-evals-trial-recording", "config_type": "trial_recording", "config": {}}]' \
