## Highest Priorities

### Platform

1. Jobs enter `queued` when executor, user, or workspace concurrency limits are reached and start in order as capacity frees; queued subprocess steps do not time out (CLI)
2. Entity filters with unsupported shapes return `400 Bad Request`; dict filters on namespace fields match per key (CLI)
3. Gateway middleware accepts `x-api-key` and can refuse calls before serving; platform services can sign attributes into access keys
4. `nemo workspaces delete` asks for confirmation and `--yes` skips the prompt in scripts (CLI); please regression test

### Agents

1. Fabric 0.6 upgrade: registration, Relay observability, and gateway telemetry routing; please regression test (CLI)
2. Agent labels, references, and run declarations on register/list/deploy (CLI)
3. Execute-agent jobs: extensions renamed to post-run actions, run context, and stored-agent skill staging; please regression test (CLI)
4. Subprocess deployments are off on the Kubernetes runtime unless `agents.subprocess_enabled: true` is set (CLI)
5. Tavily web search plugin: `nemo tavily setup` and `nemo tavily enable <agent>` work, and the proxy can be turned off (CLI)
6. Compare agent candidates with tagged traces, `nemo intake traces show`, and Compass analysis (CLI)

### Evaluation

1. Harbor taskset runs on Kubernetes: `nemo evals tasksets create`, `build-images`, `runs submit --taskset`, progress, and cancel (CLI)
2. Closed-book runs and per-trial gateway credentials limited to their models; no-network runs are refused unless the route is closed-book (CLI)
3. Harbor sandbox networking: HTTPS gateway with a private CA, allowlist agent channel, and local Docker setup caps

### Fine-tuning

1. `nemo customization dataset prepare` turns Parquet, CSV, or JSONL into a training dataset (CLI)
2. `--dry-run` and `--dry-run-full` preflight a customization job without training (CLI)
3. Per-method default learning rates, a single dataset fileset, a LoRA base deployed next to a non-LoRA serve, and a model-free NIM default; please regression test

### Other

1. Studio: Anonymizer and Data Designer job cancel asks for confirmation (Studio)
2. Capabilities that already shipped in 0.9.0 and are in range because of the supplied `0.8.1` boundary; please regression test (Studio and CLI)
