# Sum Three Numbers

Compute the sum of 8, 13 and 4.

Write a single line of text to `/app/artifacts/output.txt` in exactly this form:

```text
sum=<result>
```

For example, if the answer were 3, the file would contain `sum=3`. No spaces
around the `=`, no extra words.
