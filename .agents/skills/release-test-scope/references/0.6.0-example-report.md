## Draft release notes

These notes include only proposed capabilities with sufficient evidence. Excluded and unresolved items are omitted.

### Highlights

- Run NeMo Gym agent evaluations in a sandboxed host and evaluate NeMo Fabric harnesses with captured trajectory evidence and OTLP/Intake trace support.
- Package, publish, deploy, execute, and chat with Fabric agents through supported CLI, Jobs, and deployment-backed session workflows.
- Evaluate BEIR retrieval rankings and generate retrieval training/evaluation data through Evaluator and Data Designer.
- Start Studio agent evaluations and fine-tuning jobs through guided workflows, including ready-made Nemotron templates.

### Improvements

- Workload delegation propagates submitter identity safely into managed Docker and Kubernetes jobs.
- Agent environments separate runtime secrets, tool settings, and compute from reusable definitions; ETHOS documents the optimization intent contract.
- CLI contexts support private CAs and context deletion, while Jobs adds paginated log reads and tailing.
- GRPO configuration, environment packaging, and serialization paths are hardened; Customizer adds reranking support.
- Kubernetes operators gain documented OpenSandbox integration and workload scheduling defaults.
- Release documentation can be previewed from release branches at its final version path before the tag is cut.

### Fixes

- Anonymizer uses supported service-backed preview and platform Jobs execution rather than local in-process execution.
- Agent deployment and execution validation fails earlier for invalid images, modes, timeouts, and unsupported configurations.

### Known limitations

- Sandboxed Gym and GRPO require OpenSandbox-capable deployment configuration and shared job storage; GRPO has no local Docker fallback.
- Workload delegation requires administrator configuration.
- Studio template provisioning requires Hugging Face network access, sufficient workspace storage, and the documented GPU capacity.
- The 0.5.1 hotfix ancestry discrepancy requires Engineering/TPM confirmation before the release scope is finalized.
