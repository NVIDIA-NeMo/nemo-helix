Use **Observability > Insights** in the NeMo Studio workspace sidebar to review insights Compass generates from observed agent sessions and traces. To generate insights, run an analysis on demand or on a schedule; see [Insights from Traces](/documentation/agents/traces-and-insights/insights-from-traces).

<Note>

Insights is enabled by default. An administrator can disable it by setting `studio.feature_flags.optimizer_enabled: false` in the platform configuration and restarting Studio.

</Note>

## Get Insights

Select **Get Insights** on the Insights page, or on an agent's **Insights** tab, to start an analysis now. Choose the agent (on the Insights page), the **Fast model**, and which traces to analyze with **Traces since**: all history, since the last periodic analysis (after one has succeeded), the last 24 hours, 7 days, two weeks, or month, or a custom start date. If the agent has no insights settings yet, also choose its **Default model**; both models are saved to the agent's insights settings, with periodic analysis left off. After you start the analysis, Studio opens the agent's **Jobs** view so you can follow the run.

## Insight List

The Insights table shows each insight's status, title, source agent, number of observed traces, number of linked experiments, and creation and last-seen times. Sort by status, title, agent, or creation time. Select a row to open the insight's detail page.

An agent's **Insights** tab shows the same table for that agent, without the agent column, under the agent's total insights, open insights, and periodic analysis status. Its **Jobs** view lists the agent's analysis runs with their status; select a row to open the run's job.

## Insight Detail

The detail page shows the insight's status, source agent, description, and:

| Section | Shows |
| ------- | ----- |
| Experiments | Experiments linked to this insight, with evaluation counts and last-updated times. Select a row to open that experiment. |
| Observed Sessions | The observed sessions and traces that produced this insight, with the count in the heading. |

Available actions depend on the insight's status:

| Status | Available actions |
| ------ | ------------------ |
| Open | **Delete**, or **Resolve**. |
| Resolved or Deleted | **Reopen** — changes the insight status back to Open. |

If the insight originated an experiment, that experiment's detail page links back here. See [NeMo Studio Experiments](/documentation/studio/experiments).
