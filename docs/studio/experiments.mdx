Use **Evaluations > Experiments** in the NeMo Studio workspace sidebar to group evaluations for comparison, and to drill into evaluation results and individual runs.

<Note>

Experiments is enabled by default. An administrator can disable it by setting `studio.feature_flags.experiment: false` in the platform configuration and restarting Studio.

</Note>

## Create an Experiment

Select **New experiment** from the Experiments list. In the **Create experiment** dialog, provide a name, an optional description, and a default sort order for the experiment's evaluations, then select **Create**.

The dialog also has two optional switches:

- **Evaluate over time** shows the experiment's **Over time** chart by default. Turn it on only when every evaluation in the experiment runs against the same dataset and evaluators, so the points are comparable.
- **Favorite** pins the experiment above the rest of the Experiments list and features it in other areas of Studio, such as the agent page.

## Experiment Detail

Select an experiment to open its detail page, which shows aggregate metrics across its evaluations and a table of the evaluations in the group. The chart toggles described below open their views above the table, which stays in place.

Toggle **Over time** to plot one metric per evaluation by run date. The chart is on by default for experiments with **Evaluate over time** turned on.

Toggle **Pareto view** to plot evaluations on a chart, by default cost against latency. Change either axis to cost, latency, tokens, or any evaluator's score (`cost_usd`, `latency_ms`, `tokens`, or `evaluators.<name>`), then select the save button next to the axis selectors to store the selection as the experiment's default, which everyone who opens the experiment sees. When the saved axes have no data to plot together, such as cost for a self-hosted model, the chart falls back to an evaluator's score against cost or tokens.

Select **Edit** to update the experiment's description, default sort order, and the **Evaluate over time** and **Favorite** switches. An experiment's name can't be changed after creation.

If the experiment was created from an Optimizer insight, an **Insight description** card appears with a link back to that insight. See [NeMo Studio Insights](/documentation/studio/insights).

## Evaluation Drill-Down

Select an evaluation from an experiment's table to open its detail page, which shows aggregate metrics for that evaluation and a table of its test-case runs (sessions).

Select a session to open its detail page — the same trace and span view used by **Traces**, scoped to that test case. See [NeMo Studio Traces](/documentation/studio/traces).

## Compare Runs Side by Side

From a session's detail page, select **Compare against evaluation run** and choose another run of the same test case. Studio splits the view into two columns — the current run on the left, the selected run on the right — so you can compare trace output side by side. Select **Clear** to return to the single-run view.
