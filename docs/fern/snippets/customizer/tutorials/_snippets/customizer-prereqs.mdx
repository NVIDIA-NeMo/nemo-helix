<Accordion title="Platform Setup Requirements and Environment Variables">

Before starting, make sure you have:

- NeMo Helix installed and deployed (see [Setup](/documentation/get-started))
- The PyPI `nemo-helix` wrapper package installed (`pip install "nemo-helix[all]"`). If you are working from a source checkout, run `make bootstrap` from the repository root instead.
- A current CLI context that points at your deployment (see [Connect with CLI Contexts](/documentation/reference/cli-reference/connect-to-deployments))
- (Optional) Weights & Biases account and API key for enhanced visualization

**Set up environment variables:**

```bash
# Optional: Weights & Biases for experiment tracking
export WANDB_API_KEY="<your-wandb-api-key>"
```

**Initialize the SDK:**

```python
from nemo_helix_plugin.client.client import NemoClient

client = NemoClient.from_config()
```

These examples use the `default` workspace. If your current CLI context uses a different workspace, run `nemo config set --workspace default` first.
