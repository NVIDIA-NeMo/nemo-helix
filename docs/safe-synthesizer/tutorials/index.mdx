<a id="safe-synthesizer-tutorials"></a>

Learn how to run NeMo Safe Synthesizer jobs through hands-on tutorials to generate private synthetic versions of sensitive tabular datasets.
Each tutorial provides step-by-step guidance with executable code examples.

## Prerequisites

Before starting any tutorial, ensure you have:

- [NeMo Safe Synthesizer running](/documentation/synthesize-safe-data)
- Python environment with the PyPI `nemo-helix` package installed. If you are working from a source checkout, run `make bootstrap` from the repository root instead.
 ```bash
 pip install "nemo-helix[all]"
 ```
- Jupyter environment for running tutorial notebooks
