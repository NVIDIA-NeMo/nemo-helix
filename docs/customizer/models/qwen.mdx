<a id="model-catalog-qwen"></a>

This page provides detailed technical specifications for the Qwen model family supported by NeMo Customizer. For information about supported features and capabilities, refer to [Tested Models](/documentation/customizer-reference/models/model-catalog).

<Warning>

Deployment configurations on this page that use the multi-LLM NIM (`nvcr.io/nim/nvidia/llm-nim:1.15.5`) cannot serve merged LoRA checkpoints (`finetuning_type: lora_merged`). Deploy merged LoRA models with vLLM or the model-free NIM; see [Choose an Inference Engine](/documentation/models-and-inference/deploy-models#choose-an-inference-engine).

</Warning>

|----------|--------|

- **Full SFT**:
 - NIM Image: `nvcr.io/nim/nvidia/llm-nim:1.15.5`
 - GPU Count: 1x 80GB
 - Additional Environment Variables:
 - `NIM_MODEL_PROFILE`: `vllm`

## Qwen3-VL-8B-Instruct

| Property | Value |
|----------|--------|
| Creator | Alibaba Cloud |
| Architecture | Vision-language transformer |
| Parameters | 8 billion |
| License | Apache-2.0 |
| Default Name | Qwen/Qwen3-VL-8B-Instruct |
| Hugging Face | [Qwen/Qwen3-VL-8B-Instruct](https://huggingface.co/Qwen/Qwen3-VL-8B-Instruct) |

This is the one-GPU vision checkpoint. It fits one 48GB GPU, so it works without a cluster. It is not a Nemotron 3.5 Super VL result. For the 8-GPU Super VL profile, see [Nemotron Vision-Language Models](/documentation/customizer-reference/models/nemotron-vl).

### Training Options

- **CORD-v2 LoRA**: 1x 48GB GPU, rank 16, alpha 32. The verified run used the first 300 training rows and 30 validation rows. Walkthrough: [Fine-Tune Nemotron 3.5 Super VL on CORD-v2](/documentation/customizer-reference/tutorials/super-vl-cord-lora) with `PROFILE = "qwen3-vl-8b"`.
- **Finance OCR LoRA**: 1x 48GB GPU, rank 16, alpha 32, `attn_implementation` `sdpa`. This job checks the vision fine-tune path. It was not deployed or scored.
- **CLEVR-CoGenT GRPO**: 1x 48GB GPU. Prepare 32 training rows and 16 validation rows with `--prompt qwen`. The tool agent needs `inline_tool_output_images: true` on the policy model server and `max_rollout_turns` of 2. See [Vision-language models](/documentation/customizer-reference/grpo-and-reward-environments#vision-language-models).

### Deployment Configuration

- **vLLM**: 1x 48GB GPU, `--max-model-len 8192`.

### CORD-v2 LoRA job

```json
{
  "model": "default/qwen3-vl-8b-instruct",
  "dataset": {"training": "default/cord-v2-small"},
  "training": {
    "training_type": "sft",
    "finetuning_type": "lora",
    "lora": {"rank": 16, "alpha": 32},
    "max_seq_length": 2048
  },
  "schedule": {"epochs": 1},
  "batch": {"global_batch_size": 8, "micro_batch_size": 1},
  "optimizer": {"learning_rate": 1e-5, "min_learning_rate": 1e-6},
  "parallelism": {"num_nodes": 1, "num_gpus_per_node": 1, "tensor_parallel_size": 1},
  "deployment_config": {
    "engine": "vllm",
    "gpu": 1,
    "additional_args": ["--max-model-len", "8192"]
  }
}
```

    "finetuning_type": "lora",

    "max_seq_length": 2048,
    "max_new_tokens": 512,
    "batch_size": 8,
    "micro_batch_size": 1,
    "num_generations_per_prompt": 4,

    "max_rollout_turns": 2,
    "vllm_tensor_parallel_size": 1,
    "vllm_gpu_memory_utilization": 0.4,
    "parallelism": {"num_nodes": 1, "num_gpus_per_node": 1, "tensor_parallel_size": 1}
