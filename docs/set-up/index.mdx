<a id="nemo-ms-admin-setup-overview"></a>

This section describes how to deploy NeMo Helix to a Kubernetes cluster using the NeMo Helix Helm chart.
The chart is the supported path for self-managed clusters such as minikube, kind, EKS, AKS, GKE, OKE, OpenShift, and on-prem Kubernetes.

This Platform Setup chapter is for the following personas.

-   **Cloud administrators**: Manage Kubernetes clusters and compute/storage resources. Deploy NeMo Helix to the Kubernetes clusters on premises or cloud.

---

<a id="nemo-ms-about-parent-helm-chart"></a>
## NeMo Helix Helm Chart

The NeMo Helix Helm chart is published in the `nvidia/nemo-helix` NGC org. The chart deploys the platform API, controllers, storage integration, and dependencies required for a full self-managed deployment.

Customize the installation by updating a pinned `values.yaml` file for your target cluster. For chart assets and additional details, see the [NeMo Helix artifacts in NGC](https://catalog.ngc.nvidia.com/orgs/nvidia/teams/nemo-helix/helm-charts/nemo-helix).

The install guide uses `NHX_HELM_CHART_VERSION` so every install and upgrade is tied to a specific chart version.
