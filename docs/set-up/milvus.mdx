<a id="milvus-setup"></a>

NeMo Helix Evals uses Milvus for vector database storage for [Retrieval evaluations](/documentation/evaluate-models/metrics) and [RAG evaluations](/documentation/evaluate-models/metrics/rag-metrics).

## Configuration

To configure NeMo Helix Evals to use Milvus, set the `milvus_url` in the [platform configuration](/documentation/kubernetes-deployment/config-reference):

```yaml
evals:
 milvus_url: "milvus-standalone.default.svc.cluster.local:19530"
```

See the [platform configuration reference](/documentation/kubernetes-deployment/config-reference) for the complete NeMo Helix Evals configuration reference.
