Use this page to find the right auth troubleshooting guide. The linked pages own
the detailed steps so this page can stay short.

## First Checks

```bash
curl -s "${NHX_BASE_URL:-http://localhost:8080}/apis/auth/discovery"
nemo auth status
nemo auth token --decode
```

Use these to confirm whether auth is enabled, which context and credentials the
CLI is using, and whether token claims such as `iss`, `aud`, `email`, `scope`,
or `scp` match the deployment configuration.

## If You Are Still Stuck

- Check auth service, gateway, and PDP logs for the exact failed decision.
- Confirm the request is reaching the expected gateway or service URL.
- Compare token issuer, audience, email, groups, and scopes with the platform
  `auth` configuration.
